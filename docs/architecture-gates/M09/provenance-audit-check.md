# Provenance coverage audit — partial M09 evidence

`m09:provenance:audit` takes one PostgreSQL snapshot across every Workspace. It counts live Assistant outputs without a stored ProvenanceLink, links explicitly marked broken, and malformed or dangling recorded links. It checks every non-purged input reference resolves within the same Workspace, revision/branch source identities match the stored Message/Node, and recorded links match the direct reply input, Manifest, Run, model, endpoint and runtime snapshot. It reads no message body and fails when any of those counts is nonzero. Embedded and PostgreSQL E2E fixtures verify missing, backfilled, broken and individually corrupted recorded fields, including an extra dangling input that leaves the direct reply intact.

This proves only database coverage at the audited instant; it does not compare the complete input-reference set with encrypted Run history. It also does not prove every Replay policy, source Blob integrity, historical exported Bundle, or user-managed staging data; `provenance_replay` remains pending until those checks and the real staging audit pass.
