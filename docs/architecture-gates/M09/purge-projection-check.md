# M09 Purge projection replicas (partial)

A regression exposed plaintext left in saved Graph projection namespaces after a Node Purge: archived Node title/summary and Message excerpt remained in earlier `workspace_objects` versions. The Purge SQL transaction now redacts those rows across all versions, removes metadata and relation labels, and deletes candidates for the removed Node/Segments. A later Graph query rematerializes the active namespace without recovering the deleted text.

The embedded and isolated local PostgreSQL regression both pass. It creates two saved Graph versions, injects a failure after object redaction to prove rollback retains the pre-Purge state and does not commit a checkpoint, then repeats Purge successfully and verifies every saved version, relation label and candidate index row.

Migration 0036 also covers a target Node's sealed terminal Run and sealed Manifest v1. The embedded and isolated PostgreSQL regressions inject an old trace with body content, verify Purge rolls back before checkpoint, sanitize the trace, then verify one transaction replaces Run input/error JSON with a minimal fact and registers its input key. A forced revocation failure leaves the checkpoint pending; Run reads reject the tombstone and portable reads omit it, while recovery later revokes the key. Direct trace reinsertion and migration rollback after Purge are refused. A separate Application test confirms Replay of a purged Run returns `REPLAY_MISSING_RESOURCE` without dispatch. Foreign Run references, unsealed/active Runs and unowned resource history continue to block Purge. The full local M09 check on the isolated database passed 364 unit and 198 E2E tests (two backend-inapplicable skips) at the implementation checkpoint; the later Replay regression passed its targeted suite.

This remains partial evidence: the isolated audit database contains no business samples; unowned resource replicas, old files, WAL, backups and already exported Bundles require separate deployment evidence. `purge_replica_erasure` remains pending.
