# M11–M14 Implementation Plan

Goal: complete the approved M11–M14 engineering plan on update1002, starting at 789f54c. Linear V4.2 is the specification.

Architecture: reuse Application/UoW, immutable Run/Manifest/ResourceVersion history, scoped relational persistence, graph projection and candidate index. Keep production legacy writes closed. Extend the existing React surfaces and Node/headless host.

## Tasks

- [ ] M11: bounded SQL graph queries and incremental projection; snapshot/tail and receipt consistency, durability, 10k traces, 10k objects/50k edges, Host degradation, evidence audit and performance tools. INH-90 is observations only.
- [ ] M12: durable Stop, temporary streaming, scoped model preferences, server-side Retry lineage, stable recovery taxonomy, offline/reconnect and keyboard/accessibility states.
- [ ] M13: Conversation/Workspace management, version-anchored Segment management, indexed lexical command search, Merge target/latest-reply-full-text/explicit-summary controls.

## Interfaces and invariants

Preserve existing HTTP routes; add scoped temporary SSE, retry, command-to-run lookup, model preferences, rename/Segment/search operations. Temporary SSE ends in TEMP_RESULT, formal Chat in COMMIT. Model priority: Conversation preferredModelId, Workspace defaultModelId, existing global default; explicit unavailable preferences fail closed. New optional fields and additive migrations retain old Bundle v1 readability.

Segments retain immutable Message IDs and optional validated text-range Anchors; remove means archive, not destruction. Merge default is the latest assistant reply's full text; an explicit summary uses the existing summary parameter. Graph projection is derived; no UI state becomes Domain truth. Cache limits: 1000 objects/4000 relations. Offscreen nodes have zero DOM.

## Verification and external evidence

Use package.json tooling: pnpm run lint/build/test/licenses:verify/verify:g0/verify:m02:boundaries/verify:m04:host-boundary; add m11:checks through m14:checks. PGlite is functional acceptance, existing usable PostgreSQL supplemental only. Run affected regressions per unit, broad suite once stable. No unchanged reruns; each anomaly <=2 evidenced rounds and <=20 minutes, then preserve blocker and continue independent work.

Performance: Command p95<=200ms/p99<=500ms/G0 regression<=25%; Graph p95<=150ms/p99<=400ms; Context p95<=250ms; trace regression<=25%; 300-node interaction p95<=16ms and offscreen DOM=0. Archive environment/raw observations; 20 warmups/200 samples. Incomparable G0 environments cannot pass relative gates.

Real staging, backup expiry, continuous observation and multi-session real dogfood deferred by user choice. Formal Gates remain pending if external evidence/dependencies/performance are unresolved. No fake dogfood, business migrations, down migration, push or deployment. Commit tested units and report precise pass/pending/blocker status.
